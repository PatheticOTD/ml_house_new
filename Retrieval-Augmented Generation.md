Метод работы llm с текстом в проблемах требующих повышенной точности. 
Состоит из трех стадий:
1. Индексирование
2. Получение информации
3. Генерация

#### Indexing
На этой стадии происходит индексирование документов и сохранение в векторную базу данных для того, чтобы модель лучше ориентировалась.
#### Retrieval
По запросу пользователя модель должна понять, что ей найти в базе. можно использовать берту, чтобы она находила расстояния между запросом и документами

#### Generation
Модель использует найденную инфу и запрос пользователя, чтобы сгенерить нужный ответ
